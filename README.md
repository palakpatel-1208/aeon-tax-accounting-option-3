# Aeon Tax and Accounting Services, LLC

Static website for Aeon Tax and Accounting Services, LLC, a CPA firm in North Wales, Pennsylvania. The site is built with HTML, CSS, and vanilla JavaScript only.

## View the site

Open `index.html` in a browser, or start a local static server from this folder:

```bash
npx --yes serve .
```

## Pages

- `index.html` — Home
- `about.html` — About Us
- `services.html` — Services overview
- `service-pages/tax-services.html` — Individual and business tax services
- `service-pages/bookkeeping.html` — Bookkeeping and accounting
- `service-pages/payroll.html` — Payroll solutions
- `contact.html` — Contact form, phone, email, address, and map

## Content

Page copy follows the client brief: the home banner, three services, Our Promise, both “Why Aeon Tax?” sections, and the North Wales contact details included with the footer reference.

The contact form checks the fields in the browser, then opens the visitor’s email application addressed to `cpa.shivani@gmail.com`. It does not use a server.

Business hours and social profile URLs were not included in the brief, so they are not shown.
